# 분석 · 검증 스크립트

문서(PRD·README·AI_USAGE)에 나오는 숫자들을 **직접 재현**할 수 있는 스크립트입니다. 과제 요구 산출물은 아니지만, 판단의 근거가 어디서 나왔는지 확인할 수 있도록 함께 올립니다.

작성 순서가 곧 작업 순서입니다 — **데이터를 먼저 뜯어보고 → 처리 방식을 시뮬레이션으로 판정하고 → 만들고 → 전수 검증**했습니다.

---

## 실행

의존성이 없습니다. 저장소 루트의 `dummy_creators.csv`를 자동으로 참조합니다.

```bash
python3 analysis/profile_creators.py
python3 analysis/sim_neutral.py
node analysis/sim_all.js
node analysis/sim_all2.js
node analysis/sim_weights.js
```

`sim_all.js` · `sim_all2.js`는 `index.html`에서 스코어링 로직을 직접 추출해 실행합니다. **프로토타입과 검증이 같은 코드를 쓰므로**, 로직을 고치면 검증 결과도 함께 바뀝니다.

---

## 각 스크립트가 답한 질문

### `profile_creators.py` — 이 데이터는 어떻게 생겼나

분포·결측·이상치를 훑습니다. 여기서 나온 숫자가 이후 모든 판단의 출발점이 됐습니다.

- 참여율이 **p25 6.47 / 중앙값 7.10 / p75 7.90** — 전 구간이 1.4%p 안에 몰려 변별력이 없음 → 참여율 단독 가중치를 뺀 근거
- 조회수 최대값이 중앙값의 **53배** → min-max 대신 백분위를 쓴 근거
- `advertiser_rating` 결측 27명이 **전원 집행 이력 0건** → "결측"이 아니라 "신인"이라는 발견
- `avg_campaign_budget_krw`에 **0원 27건** → 과제에 예고되지 않은 예외 발견

### `sim_neutral.py` — 신인을 중립 처리하면 정말 공정한가

"평점을 중앙값으로 채워주면 불이익이 없다"는 가정을 검증했습니다.

```
0점 처리   → 27명 순위: 최고 132위 / 중앙 184위 · TOP50 진입 0명
중립 처리  → 27명 순위: 최고  65위 / 중앙 152위 · TOP50 진입 0명
```

**가정이 틀렸습니다.** 평점을 보정해도 집행 경험 축에서 전원 0점이라 구조적으로 올라올 수 없었습니다. 가중치로는 풀리지 않는 문제라고 판단해, 방향을 "점수 조정"에서 **"노출 구조 분리"** 로 바꿨습니다.

### `sim_all.js` — 모든 입력 조합에서 정상 동작하는가 (1차)

예산 × 팔로워 규모 × 카테고리 × 인원을 전수로 돌려, 인원 미충족·예산 초과·조합 실패를 탐지합니다. 여기서 자동 모드의 인원 산정 방식 문제를 발견했습니다.

### `sim_all2.js` — 플랫폼 필터 추가 후 재검증 + 미사용 신호 탐색 (2차)

**검증** — 1,287 조건 × 인원 5종 × 대안 3회 = **19,305회**

| 항목 | 결과 |
|---|---|
| 점수 범위 이탈 · NaN | 0건 |
| 예산 초과 · 인원 초과 · 중복 포함 | 0건 |
| 채울 수 있는데 못 채운 조합 | 0건 (수정 전 19건) |

수정 전 걸린 19건은 "다른 조합 보기"의 후보 회전이 저단가 재구성 단계까지 적용돼, 예산으로 채울 수 있는데도 인원을 못 채우던 버그입니다. **특정 예산·카테고리·인원·2번째 대안에서만 나타나 손으로는 찾을 수 없는 조건**이었습니다.

**탐색** — 아직 쓰지 않은 신호가 있는지 확인

| 발견 | 채택 여부 |
|---|---|
| 도달 1인당 비용(CPR) 111원 ~ 55,089원, **498배 차이** | 표시·정렬로 채택 (점수 편입은 기각) |
| 조회수/팔로워 중앙값 유튜브 20.9% · 인스타 33.1% | 플랫폼별 하위 10%를 주의 태그로 채택 |
| 평점이 다른 지표와 전부 무상관 (±0.07 이내) | 30% 가중치의 근거로 문서에 반영 |
| 단가 ↔ 참여율 **-0.51** (비쌀수록 반응 밀도 낮음) | 단가를 점수 축에서 뺀 근거로 반영 |
| 집행 25건 이상 = 광고 피로도 가설 | **기각** — 평점 4.39 vs 전체 4.42로 차이 없음 |

마지막 항목을 기각한 것이 이 탐색에서 중요했습니다. 그럴듯한 가설이었지만 숫자를 대보니 근거가 없었습니다.

### `sim_weights.js` — 가중치 45/30/25는 근거가 있는가

**가장 예상되는 질문에 대한 답입니다.** 45/30/25가 최적이라는 근거는 없습니다. 그래서 "이 값이 결과를 얼마나 좌우하는가"를 먼저 측정했습니다.

```
40/35/25    TOP10 10/10 유지 · 1위 동일
50/30/20    TOP10  9/10 유지 · 1위 동일
33/34/33    TOP10  9/10 유지 · 1위 동일
```

**±5 범위에서는 순위가 거의 바뀌지 않습니다.** 반면 축을 제거하면 무너집니다.

```
도달 제거    TOP10 6/10
평점 제거    TOP10 4/10   ← 가장 큼
경험 제거    TOP10 6/10
```

**중요한 결정은 "비율을 몇으로 할까"가 아니라 "어떤 축을 쓸까"였습니다.** 평점 제거의 영향이 가장 큰 것은, 평점이 다른 지표와 무상관인 독립 신호이기 때문입니다(`sim_all2.js` 4번 항목).

단가를 4번째 축으로 넣는 안도 검증했습니다. **순위는 흔들리는데 TOP10 평균 도달이 오히려 떨어져** 채택하지 않았습니다.
